================================================================================
          PROBLEM 4 – STABLE MATRIX ANALYSIS REPORT
================================================================================
Problem Description:
An n x n integer matrix is called stable if every non-boundary (interior) element 
satisfies:
    A[i][j] = A[i-1][j] + A[i+1][j] + A[i][j-1] + A[i][j+1]

Determine whether the matrix is stable. If it is not, report:
1. Total number of violating elements.
2. Positions (i, j) of all violating elements.
3. Position having the maximum absolute difference D(i, j):
    D(i, j) = |A[i][j] - (A[i-1][j] + A[i+1][j] + A[i][j-1] + A[i][j+1])|

--------------------------------------------------------------------------------
1. ALGORITHM DESIGN & PSEUDOCODE
--------------------------------------------------------------------------------
- If matrix size n < 3, report Matrix is Stable (no interior elements exist).
- Initialize violating_positions list, max_abs_diff = -1, max_diff_position = None.
- Iterate row_index from 1 to n-2:
    - Iterate col_index from 1 to n-2:
        1. Calculate neighbour_sum = A[row_index - 1][col_index] + A[row_index + 1][col_index] + 
                                   A[row_index][col_index - 1] + A[row_index][col_index + 1].
        2. Calculate current_value = A[row_index][col_index].
        3. If current_value != neighbour_sum:
            a. Add (row_index, col_index) to violating_positions list.
            b. Compute absolute difference: abs_diff = |current_value - neighbour_sum|.
            c. If abs_diff > max_abs_diff:
                - Set max_abs_diff = abs_diff
                - Set max_diff_position = (row_index, col_index).
- If len(violating_positions) == 0, matrix is STABLE.
- Otherwise, return violation count, positions list, max_diff_position, and max_abs_diff.

--------------------------------------------------------------------------------
2. REQUIREMENT OF AN ADDITIONAL MATRIX
--------------------------------------------------------------------------------
Question: Is an additional matrix required to solve this problem?
Answer: NO. An additional matrix is NOT required.

Reasoning:
- Matrix stability is a read-only evaluation.
- Calculating neighbour sums for cell A[i][j] reads only original values from 
  the input matrix without overwriting or modifying any elements.
- Storing output results requires only primitive counters, coordinates, and max values.
- Therefore, the algorithm operates directly in-place on the input matrix.

--------------------------------------------------------------------------------
3. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
Let n = number of rows / columns in the n x n matrix.

Time Complexity:
- Best-Case Time Complexity: O(n^2)
  Even if an early violation is detected, determining whether the matrix is stable, 
  counting all violating elements, and identifying the global maximum difference 
  D(i, j) requires scanning all (n-2)^2 interior elements.

- Worst-Case Time Complexity: O(n^2)
  There are (n-2) x (n-2) interior elements. For each cell, performing 4 neighbour 
  additions, 1 subtraction, and 1 comparison takes constant O(1) time.
  Total Time = (n-2)^2 * O(1) = O(n^2).

Auxiliary Space Complexity:
- Auxiliary Space Complexity: O(1) (excluding space for reported violation positions).
  No extra matrix or grid structures are created. Memory allocation remains constant.
